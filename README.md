A travel poster for Velmora — a floating sky-harbour above a sea of clouds, where glass-sailed ships dock at sky-piers and a lighthouse keeps the cloud-sea lanes lit. Rendered entirely in code (pure Node 22, no dependencies, no network): a 2x-supersampled vector scene with hand-drawn stroke type, written to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
